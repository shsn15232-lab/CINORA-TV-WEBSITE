# CINORA TV Website

Arabic RTL landing page built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

## Deploy
Import this repository into Vercel. Framework preset: Next.js. Build command and output directory can remain on their defaults.

The app download URL is intentionally not configured yet; add the official APK link to the download section in `app/page.jsx` when it is ready.
